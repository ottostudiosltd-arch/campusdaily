# 🎓 College Daily — Every Campus Has a Story

> Maharashtra's Centralized College News & Entertainment Network  
> Starting in Pune, expanding across Maharashtra.

---

## 🚀 Live Demo
- **GitHub Pages:** [https://ottostudiosltd-arch.github.io/campusdaily/](https://ottostudiosltd-arch.github.io/campusdaily/)
- **Local Dev Server:** `http://localhost:3000`

---

## 🎨 Tech Stack & Features
- **Frontend:** React 18 + TypeScript + Vite
- **Styling:** Tailwind CSS + Neobrutalism & Gen-Z Pastel Design System
- **Icons & Doodles:** Lucide Icons + Handcrafted Mascot Stickers (Thinking Guy, Scrolling Girl, Cool Cat, Hype Ghost)
- **Deployment:** GitHub Pages (Automated via GitHub Actions)
- **Features:**
  - 🍑 **Theme 1:** Peach Doodle Question Card (Discussions & Attendance)
  - 📸 **Theme 2:** Photo Spotlight Card (College Fests & Sports)
  - 🐸 **Theme 3:** Mint Meme Card (Canteen Chronicles & Relatable Humor)
  - ⚡ **Theme 4:** Opportunity & Notice Card (Hackathons & Internships)
  - 🗞️ **Dedicated News Wire:** Top category mini-filters (Confessions, Trending, Spotted, Memes, Events, Incidents)
  - 🏛️ **Colleges Hub:** Campus filtering for COEP, MIT-WPU, PICT, Fergusson, Symbiosis, VIT, DY Patil, GHRSTU
  - 👤 **Student Profile & Reporter ID:** Submission tracking, bookmarks, digital press card

---

## 💻 Local Development

```bash
# Clone the repository
git clone https://github.com/ottostudiosltd-arch/campusdaily.git

# Install dependencies
npm install

# Run dev server
npm run dev

# Build for production
npm run build
```
